# 科研与评估规范

## 数据泄漏是 EEG 机器学习的头号风险之一

同一受试者、同一记录或相邻窗口高度相关。把窗口随机分到训练集和测试集，模型可能只学会受试者或记录特征。

- 个体内研究：按会话或连续时间块划分。
- 跨个体研究：测试受试者从训练和调参过程中完全隔离。
- 交叉验证：预处理参数、特征选择和标准化必须放进每个训练折内部。
- 测试集：只用于一次最终报告，不能反复挑模型。

## 指标要对应临床问题

- 类别不平衡分类：Balanced Accuracy、Macro-F1、AUROC/AUPRC。
- 癫痫连续检测：事件敏感度、误报/小时、延迟，而不只是窗口 Accuracy。
- 睡眠分期：Macro-F1、Cohen's κ、逐阶段召回率和混淆矩阵。
- 麻醉回归：MAE、RMSE、相关/一致性，并按患者划分。
- BCI：准确率之外报告校准时间、跨会话性能和 ITR 的假设。

## 最小可复现报告

固定数据版本、受试者排除标准、通道、参考、滤波、重采样、Epoch、伪迹规则、划分、随机种子、软件版本和硬件。所有结论都应同时说明外部有效性与潜在混杂因素。
