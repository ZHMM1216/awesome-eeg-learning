# 卒中 EEG

卒中 EEG 研究横跨急性期评估、预后、生物标志物、运动意图解码和康复干预。入门时最重要的不是立即训练复杂模型，而是明确患者阶段、任务终点和临床结局。

![运动想象 Mu Beta ERD 概念时频图](assets/figures/motor-imagery-erd.svg)

*图解：这张健康模式示意只用于教读图；卒中患者可能因病灶、缺损和任务完成度呈现不同或不对称模式。*

## 先区分四类研究问题

| 问题 | EEG 输入 | 目标 | 合适的验证单位 |
|---|---|---|---|
| 急性状态描述 | 静息态或任务 EEG | 患侧不对称、网络改变 | 患者 |
| 运动意图解码 | 运动想象/尝试 Trial | 左右侧、意图有无 | Session 与患者 |
| 预后预测 | 基线 EEG + 临床变量 | 后续量表或功能结局 | 患者，最好外部队列 |
| 康复疗效 | 多时间点 EEG + 干预 | 临床量表变化 | 随机分组与纵向患者 |

“分类正确”只能回答解码问题；要证明康复有效，需要预先定义的临床终点、合适对照和随访。

## 第一条可复现路线

1. 先建立患者数据卡：病灶侧、受影响侧、发病时间、优势手、临床量表、Session。
2. 检查通道、事件、缺失 Trial 和任务完成度；患者无法完成的 Trial 不能悄悄删除。
3. 在 C3/C4 周围比较左右任务的 Mu/Beta 时频变化。
4. 建立训练折内拟合的带通 + CSP + LDA 患者内基线。
5. 再做留一患者验证，比较个体化与跨患者性能。
6. 报告每位患者结果、置信区间和失败案例，不只给所有 Trial 的总平均。

## 评价与混杂

- **划分**：同一患者、Session 或 Trial 的重叠窗口不得跨集合。
- **指标**：二分类报告 Balanced Accuracy、ROC-AUC 或 PR-AUC，并显示患者级分布。
- **临床变量**：年龄、病灶、运动缺损、药物和认知能力可能同时影响 EEG 与结局。
- **侧化**：将所有患者简单左右翻转到“患侧/健侧”前，要说明电极映射和病灶异质性。
- **缺失数据**：严重患者更可能无法完成任务，完整案例分析可能产生选择偏倚。

## 分阶段练习

| Level | 任务 | 交付物 |
|---:|---|---|
| 1 | 单患者时频分析 | C3/C4 ERD/ERS 图与 Trial 质控 |
| 2 | 单患者 CSP+LDA | 折内流水线、Balanced Accuracy |
| 3 | 留一患者验证 | 每患者结果和失败分析 |
| 4 | EEG + 临床变量 | 预注册特征、嵌套验证、校准图 |

!!! warning "解释边界"
    运动想象可解码不等于患者能够因此恢复；相关性不等于 EEG 是独立预后生物标志物。任何临床结论都需要相应研究设计和外部验证。

??? question "完成本节前自测"
    - 为什么要同时保存病灶侧、受影响侧和优势手？三者不一定相同。
    - 为什么患者内高准确率不能证明可用于新患者？模型可能学习个体特征，需留一患者验证。
    - 为什么临床量表变化比 Trial Accuracy 更接近康复疗效？前者是患者相关结局，后者只是解码性能。
