# 卒中 EEG

卒中方向常见任务包括静息态生物标志物、运动执行/运动想象解码、康复反馈和纵向恢复预测。本项目重点从运动想象入门，因为它能连接经典 BCI 方法与康复研究。

## 首个实验

使用 MOABB 的 `Liu2024` 数据类，先读取一名急性卒中患者：

1. 检查病灶侧、受影响侧、通道和事件。
2. 比较左右手试次的感觉运动区时频功率。
3. 用 CSP+LDA 做个体内演示。
4. 再扩展到按患者留一验证，禁止窗口随机混分。

## 解读边界

解码准确率不等同于康复有效。研究还需考虑病灶位置、发病时间、运动功能量表、药物、疲劳、患者能否理解并执行想象任务等因素。

必读起点包括 Cervera 等人的 BCI 康复荟萃分析（[DOI](https://doi.org/10.1002/acn3.544)）和 Liu 等人的开放数据论文（[DOI](https://doi.org/10.1038/s41597-023-02787-8)）。
