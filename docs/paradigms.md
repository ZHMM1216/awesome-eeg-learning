# 经典 EEG 范式

## 睁眼/闭眼 Alpha

闭眼时枕区约 8–13 Hz Alpha 功率通常增强。它适合学习原始波形、PSD、频带功率、空间分布和个体差异，但不应把固定频段边界当作每个人的生理真值。

## Oddball / P300

低概率目标刺激常在刺激后约 300 ms 出现正向 ERP。教程采用听觉 Oddball 数据，完成事件检查、平均、头皮图、xDAWN+LDA 和 ROC-AUC。

## SSVEP

以稳定频率闪烁的视觉刺激会在枕区诱发同频及谐波响应。先用 PSD 确认频谱峰，再比较简单频带功率与 CCA 分类。

## 运动想象

想象左右手运动可改变对侧感觉运动区 Mu/Beta 节律。经典流程是时频 ERD/ERS、CSP 空间滤波和 LDA；评估必须区分个体内、跨会话和跨个体。

## Flanker / ERN

错误反应后约几十毫秒可观察到额中央负向成分。分析通常按反应而不是刺激锁定，并需控制正确/错误试次数不平衡。

## 人脸 N170

人脸刺激常在枕颞区约 170 ms 引出负向成分。该范式适合学习刺激匹配、峰值测量、多重比较和对“成分特异性”的谨慎解释。
