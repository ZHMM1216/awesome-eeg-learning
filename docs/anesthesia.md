# 麻醉 EEG

麻醉 EEG 不是一个随“深度”单调变化的统一波形。药物类型、剂量、年龄、合并用药、刺激、伪迹和个体脑状态都会影响频谱。

## 学习顺序

1. 同时查看原始波形和谱图。
2. 识别慢波、前额 Alpha、Beta 活动和爆发抑制。
3. 计算频带功率、谱边缘频率和抑制率等透明指标。
4. 再理解 BIS 等处理指数的设计、延迟和限制。

## 数据

PhysioNet GABA 麻醉数据适合研究意识消失/恢复的频谱动力学，但需要完成 PhysioNet 凭证流程。VitalDB 含部分 BIS EEG 波形与 BIS、SQI、SEF、SR，同样必须遵守数据使用协议。

!!! danger "禁止闭环给药"
    本项目不会实现或建议真实麻醉闭环控制。任何给药决策都必须由有资质的麻醉专业人员完成。
