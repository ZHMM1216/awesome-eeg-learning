# 麻醉 EEG

麻醉 EEG 不是随单一“深度”轴单调变化的统一波形。药物类别、剂量、年龄、合并用药、刺激、体温、伪迹和患者脑状态都会改变频谱。学习时应同时观察原始波形和谱图，而不是只看 BIS 等处理指数。

### 谱图的读法

横轴是术中时间，纵轴是频率，颜色代表局部功率。先把给药、刺激、意识反应和伪迹事件对齐，再观察慢波、Alpha、Beta 与抑制随时间怎样共同变化。单个 BIS 数值压缩了这些结构，也可能有平滑和延迟。

## 常见模式与边界

| 模式 | 可能观察 | 解释注意 |
|---|---|---|
| 慢波 | 低频功率增加 | 多种状态均可出现，不具药物唯一性 |
| 额叶 Alpha | 丙泊酚等 GABA 能麻醉中常见 | 年龄和药物会改变强度与频率 |
| Beta 活动 | 某些镇静药或浅状态可见 | 肌电也可能增加高频功率 |
| 爆发抑制 | 爆发与近等电位抑制交替 | 检测阈值、滤波和伪迹影响抑制率 |
| 高频/非典型模式 | 氯胺酮等药物可不同 | 不能用单一模板解释所有药物 |

## 数据入口

| Dataset | 内容 | Access | 适合练习 |
|---|---|---|---|
| [GABA anesthesia](https://physionet.org/content/eeg-gaba-anesthesia/1.0.0/) | GABA 能麻醉意识消失/恢复的 EEG 动力学 | PhysioNet 凭证、培训与协议 | 频谱随意识状态变化 |
| [VitalDB](https://vitaldb.net/dataset/) | 6388 例术中多参数数据，部分含 EEG/BIS/SQI/SEF/SR | 数据使用协议 | 波形、指数和生理信号对齐 |

仓库不会代下载或重新分发受限数据。先阅读数据卡和协议，再用最少病例验证加载流程。

## 第一条可复现路线

1. 检查 EEG 单位、采样率、导联、参考和设备滤波。
2. 将原始波形、谱图、药物事件、BIS、SQI、SEF 和 SR 放在同一时间轴。
3. 标记电刀、体动、眼动、断电极和饱和伪迹；SQI 也不能代替人工质控。
4. 计算相对频带功率、谱边缘频率和透明的爆发抑制率。
5. 以个体时间轨迹为主，不把每秒样本当作独立病例。
6. 比较意识状态或药物阶段时按患者划分，并调整年龄等预先指定因素。

运行仓库的透明特征示例：

```bash
python examples/clinical/anesthesia_spectral_features.py
```

## 评价设计

- **状态标签**：行为反应、给药时间、BIS 阈值并不等价，应明确标签来源。
- **时间延迟**：处理指数可能有平滑和延迟，不能当作同步真值。
- **重复测量**：一位患者的数万时间点不是数万名独立受试者。
- **泛化**：设备、医院、药物方案和年龄变化都可能造成分布偏移。
- **安全边界**：离线相关分析不能直接推导闭环给药策略。

??? question "完成本节前自测"
    - 为什么不能用 BIS 当作训练模型的无误差真值？它本身是经过处理、有延迟且受伪迹影响的指数。
    - 为什么每秒数据点不能视为独立病例？同一患者时间点高度相关。
    - 为什么离线识别意识状态不能直接变成闭环给药？安全、因果、实时延迟和医疗器械验证均未解决。
