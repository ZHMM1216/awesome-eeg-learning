# 精选论文

论文目录按照“基础与工具、经典范式、卒中、癫痫、睡眠、麻醉”组织。每条记录都保留真实 DOI、代码关系和中文导读，机器可读原始目录位于 `catalog/papers.yml`。

## 选择原则

- 经典论文：建立范式、方法、数据或工具标准的代表工作。
- 近五年：本项目固定为 2022–2026，优先数据论文、评估规范、可复现方法和外部验证。
- 每个方向同时包含“理解问题”的论文与“动手复现”的资源。
- 未找到作者公开代码时明确标记，不用无关仓库填空。

运行 `eeg-catalog --online` 可重新解析全部 DOI。GitHub Actions 每周检查一次 DOI 和外部链接。
