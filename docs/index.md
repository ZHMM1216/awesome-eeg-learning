# 从脑电波形到可复现研究

Awesome EEG Learning 是一套中文优先、科研规范优先的 EEG 入门材料。它不把 EEG 简化成“把时序丢给神经网络”，而是从信号形成、实验范式、预处理、可视化和正确评估逐步推进到临床研究。

!!! warning "仅限教学科研"
    本项目不是医疗器械，不能用于诊断、治疗、麻醉给药或患者监护。临床 EEG 必须由具备资质的专业人员结合完整临床信息解释。

## 你会学到什么

- 理解 10–20 电极系统、参考、体积传导、采样率和常见伪迹。
- 用 MNE 读取 EDF、BrainVision、EEGLAB 和 EEG-BIDS 数据。
- 从原始波形走到 PSD、ERP、头皮图、时频图和经典机器学习。
- 复现 P300、SSVEP、运动想象、ERN 等经典范式。
- 理解卒中、癫痫、睡眠与麻醉研究中“标签”和“评估”分别意味着什么。
- 避免窗口级随机划分、测试集调参、伪重复和只报告 Accuracy 等常见错误。

## 推荐路线

先完成“EEG 基础”和经典范式，再进入一个临床方向。第一次运行只选一名受试者或一个夜晚，确认数据和图形合理后再扩大规模。
