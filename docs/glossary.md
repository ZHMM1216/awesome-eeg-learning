# EEG 初学者术语表

这份术语表优先解释“它在分析中意味着什么”和“最容易误解什么”。

## 信号与电极

| 术语 | 初学者解释 | 常见误区 |
|---|---|---|
| EEG | 头皮电极测得的电势差随时间变化 | 不是单个神经元放电 |
| Channel | 一个活动电极相对于参考的信号 | 通道值不是绝对电压 |
| Reference | 所有通道进行电势差计算的基准 | 改参考会改变所有波形和拓扑 |
| Montage | 电极或导联的组织与命名方式 | 同名数据集未必使用同一 Montage |
| 10–20 system | 按头部比例放置电极的标准体系 | 数字不是电极间固定厘米数 |
| Sampling rate | 每秒保存的采样点数，单位 Hz | 高采样率不会自动带来高质量 |
| Nyquist frequency | 采样率的一半 | 目标频带应给抗混叠滤波留过渡区 |
| Amplitude | 波形相对参考的大小，EEG 常用 µV | 单位错误可造成千倍差异 |
| Frequency | 每秒重复次数，单位 Hz | 非正弦瞬态也会产生宽频谱 |
| Phase | 周期信号在循环中的位置 | 相位关系对滤波和时间锁定敏感 |
| Power | 某段信号能量大小的表示 | 绝对功率、相对功率不可混写 |

## 实验与表示

| 术语 | 初学者解释 | 常见误区 |
|---|---|---|
| Event | 刺激、反应或状态变化的时间标记 | 软件日志时间不一定等于真实呈现时间 |
| Epoch | 围绕事件截取的一段信号 | 相邻 Epoch 可能重叠并高度相关 |
| Baseline | 用于比较或校正的参考时间段 | 基线本身可能含任务预期活动 |
| Trial | 一次完整任务尝试 | 一个 Trial 可被切成很多窗口，但仍非独立样本 |
| ERP | 跨事件锁定 Trial 平均的电位 | 不是每个单试次都清晰存在同样峰 |
| PSD | 功率随频率的分布 | 参数不同的 PSD 数值不可直接比较 |
| Time-frequency map | 功率随时间和频率的二维变化 | 颜色必须结合基线、单位和色标解释 |
| Topomap | 头皮电极值的空间插值图 | 不是脑内源定位图 |
| ERD/ERS | 相对基线的节律功率下降/上升 | 正负号取决于定义和绘图方式 |

## 预处理

| 术语 | 初学者解释 | 常见误区 |
|---|---|---|
| High-pass filter | 减弱低于截止频率的慢变化 | 过高截止可扭曲慢 ERP |
| Low-pass filter | 减弱高于截止频率的快速变化 | 不能自动区分肌电和脑高频活动 |
| Notch filter | 针对工频附近的窄带抑制 | 不是所有数据都必须机械使用 |
| Re-reference | 改变电势差的参考定义 | 不等于简单“降噪” |
| ICA | 将混合信号分解为统计独立成分 | 不能自动知道哪个成分是伪迹 |
| Bad channel | 平直、饱和、异常噪声等不可用通道 | 插值不能创造真实信息 |
| Resampling | 改变采样率 | 降采样前需要抗混叠滤波 |

## 建模与评价

| 术语 | 初学者解释 | 常见误区 |
|---|---|---|
| Feature | 从信号计算的模型输入 | 在全数据上选特征会泄漏测试信息 |
| CSP | 最大化两类空间方差差异的空间滤波 | 必须只在训练折中拟合 |
| CCA | 比较 EEG 与正弦/余弦参考的相关结构 | 谐波和窗口长度会影响结果 |
| Cross-validation | 重复训练/验证以估计泛化 | 随机窗口 CV 常泄漏受试者身份 |
| Balanced Accuracy | 各类别召回率的平均 | 比普通 Accuracy 更适合不平衡，但仍非万能 |
| Macro-F1 | 各类 F1 等权平均 | 不显示具体哪一类失败 |
| AUROC | 不同阈值下排序能力 | 极不平衡任务还应看 PR-AUC |
| Calibration | 预测概率与真实发生率的一致程度 | AUC 高不代表概率可信 |
| External validation | 在独立来源数据上验证 | 随机留出同一数据集不等于外部验证 |
| Data leakage | 测试信息直接或间接进入训练 | 标准化、ICA、特征选择也可能泄漏 |

## 临床研究

| 术语 | 初学者解释 | 常见误区 |
|---|---|---|
| Biomarker | 与生理、疾病或结局相关的可测指标 | 相关不等于可诊断或可干预 |
| Sensitivity | 真阳性事件中被检出的比例 | 不说明误报有多少 |
| False alarms/hour | 每小时无效报警数 | 需要明确报警合并和容差规则 |
| Detection latency | 事件开始到报警的时间 | 离线零相位处理会低估实时延迟 |
| Hypnogram | 整夜睡眠阶段时间序列 | 单 Epoch 准确不等于结构合理 |
| Burst suppression | 爆发和低幅抑制交替的模式 | 自动阈值受设备和伪迹影响 |
| Clinical endpoint | 研究预先定义的患者相关结局 | 解码准确率通常不是临床终点 |
