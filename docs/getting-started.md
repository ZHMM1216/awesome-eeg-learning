# 环境与 10 周学习路线

这条路线默认你会基础 Python，但不要求神经科学、信号处理或医学背景。每周建议投入 4–6 小时：约 1/3 阅读、1/3 看图与检查数据、1/3 运行和修改代码。

## 开始前准备

| 项目 | 最低建议 | 为什么 |
|---|---|---|
| Python | 3.10–3.12 | 神经科学依赖兼容较稳定 |
| 内存 | 8 GB，推荐 16 GB | 单人教学数据足够，整库需更高 |
| 磁盘 | 至少 10 GB | 数据缓存不进入 Git |
| 计算 | CPU 即可 | 先学经典方法，深度学习是选修 |
| 数学 | 均值、方差、相关、矩阵直觉 | 遇到公式再补，不必先学完整教材 |

## 10 周详细计划

| 周 | 核心问题 | 阅读与看图 | 动手任务 | 完成证据 |
|---:|---|---|---|---|
| 1 | EEG 到底测到了什么？ | 电势差、参考、10–20 电极图 | 读取 Raw，检查单位/通道/采样率 | 一页数据卡 |
| 2 | 哪些波形不像脑活动？ | 漂移、眼电、肌电、工频、饱和 | 浏览完整记录，标记坏段和坏道 | 带注释原始波形 |
| 3 | 预处理改变了什么？ | 滤波、重参考、重采样、ICA | 每次只改一个处理，比较前后 | 参数与影响对照表 |
| 4 | 频谱如何描述节律？ | PSD、1/f、绝对/相对功率 | 完成睁闭眼 Alpha | PSD + 枕区拓扑 |
| 5 | 平均如何显露 ERP？ | Event、Epoch、基线、P300 | 目标/标准 ERP 与差异波 | Trial 数 + ERP + 时间窗 |
| 6 | 如何解码频率标记？ | SSVEP 基频/谐波、CCA | 比较 1/2/4 秒窗口 | Accuracy 与窗口时长图 |
| 7 | 如何解码运动想象？ | Mu/Beta ERD/ERS、CSP | CSP+LDA 折内流水线 | 时频图 + CV 分布 |
| 8 | 临床标签回答什么？ | 选卒中/癫痫/睡眠/麻醉 | 写任务定义和数据纳入表 | 临床问题—标签—指标表 |
| 9 | 如何证明模型能泛化？ | 泄漏、受试者级划分、校准 | 比较错误窗口划分与正确划分 | 两套结果和原因分析 |
| 10 | 别人能否复现？ | 数据版本、环境、随机种子、限制 | 从空目录重跑最小实验 | README、配置、结果表 |

## 每周学习笔记模板

```text
问题：我今天要回答什么？
数据：数据集、版本、受试者、记录和标签是什么？
检查：单位、采样率、参考、坏道、事件有什么问题？
方法：每个处理参数是什么，为什么选择？
结果：最重要的一张图和一个指标是什么？
失败：哪些人、Trial 或阶段没有达到预期？
边界：结果不能说明什么？
下一步：只改变哪一个因素？
```

## 下载策略

所有下载放入本地 `data/` 或 MNE/MOABB 缓存，已经被 `.gitignore` 排除。先下载一名受试者或一晚记录，确认流程后再扩展。受限数据必须由使用者本人注册、完成培训并同意官方条款。

## 初学者常见卡点

| 现象 | 优先检查 |
|---|---|
| 图上几乎是一条直线 | 单位是否以 V/µV 混淆，缩放是否合理 |
| 通道位置图报错 | 通道命名是否标准，Montage 是否设置 |
| Event 数量不对 | 注释文本、事件映射、重复/缺失触发 |
| 滤波后边缘振荡 | 滤波器长度、过渡带、边界和短 Epoch |
| 准确率异常接近 100% | 数据泄漏、标签编码、伪迹或重复窗口 |
| 换一个人性能崩溃 | 个体差异、通道差异、会话偏移与过拟合 |

!!! success "何时可以进入临床方向"
    你应能独立解释原始波形、PSD、ERP 和时频图，能把预处理放入交叉验证流水线，并能说明为什么同一患者的窗口不能随机分到训练和测试两边。
