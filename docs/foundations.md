# EEG 基础：先理解测量，再处理信号

头皮 EEG 主要反映大量神经元突触后电位同步活动经脑组织、脑脊液、颅骨和头皮体积传导后形成的电势差。它空间分辨率有限、幅值很小，并且始终相对于某个参考电极或参考组合。

## 1. 先认识通道位置

<small>鼻尖朝上。奇数多在左侧，偶数多在右侧，z 表示中线。</small>

电极前缀提供位置线索：Fp 为额极、F 为额区、C 为中央、P 为顶区、O 为枕区、T 为颞区。它们不是“脑区传感器”；体积传导意味着一个头皮电极会混合多个源。

## 2. 五个必须先核对的数字

| 数字 | 典型表示 | 错了会怎样 |
|---|---|---|
| 采样率 | Hz，如 100、250、500 | 影响 Nyquist 频率、滤波和时间轴 |
| 幅值单位 | V、mV、µV | V 与 µV 混淆造成百万倍差异 |
| 通道数 | EEG/EOG/EMG/ECG 分开 | 把 EOG 当 EEG 会产生虚假高性能 |
| 记录时长 | 秒/分钟/小时 | 影响事件率、窗口数和误报/小时 |
| 事件延迟 | 样本点或秒 | ERP 峰会被平移或平均掉 |

进入[采样与混叠实验室](labs/sampling.md)，亲手观察采样率不足如何生成假频率。

### 用时间尺度判断，而不是只看形状

| 现象 | 常见时间/频率特征 | 辅助判断 |
|---|---|---|
| 慢漂移 | 极低频、几十秒变化 | 多通道共同偏移，可能来自电极/出汗 |
| 眨眼 | 额区大幅慢瞬态 | Fp1/Fp2 最明显，与 EOG 同步 |
| 水平眼动 | 左右额颞极性相反 | 与注视方向或任务事件相关 |
| 肌电 | 20 Hz 以上宽带增强 | 颞区/额区明显，伴咬牙或皱眉 |
| 工频 | 50 或 60 Hz 窄峰 | PSD 上非常稳定的尖峰 |
| 电极弹跳 | 突然大幅阶跃 | 单通道突出，恢复过程较慢 |
| 饱和/平直 | 到达设备上下限或无变化 | 不是“安静大脑” |

## 4. 参考决定你看到的电势差

若通道写作 `C3 - Ref`，改变 Ref 会改变 C3，也会改变所有其他通道。平均参考、乳突参考、Cz 参考和双极导联各有假设。

- **平均参考**：假设电极覆盖较均匀；坏道会污染平均。
- **乳突参考**：参考本身仍可能有脑信号或肌电。
- **双极导联**：看相邻电极差，临床 Montage 常用；空间含义不同于单极通道。
- **REST/源空间参考**：属于进阶方法，需要额外模型假设。

不要把“换参考后效果更好”直接解释为生理增强。报告原始参考和分析参考，并在换参考前先处理坏道。

### 滤波器不是“清洁按钮”

| 操作 | 可能用途 | 主要风险 |
|---|---|---|
| 高通 | 减少慢漂移 | 过高截止会扭曲慢 ERP 与基线 |
| 低通 | 限制高频噪声 | 不能自动区分肌电与脑高频活动 |
| 陷波 | 减弱 50/60 Hz 工频 | 振铃、频段信息损失、机械套用 |
| 重采样 | 降低计算量、统一频率 | 必须先抗混叠；事件点需同步转换 |

每次保存：滤波类型、截止频率、过渡带、阶数/长度、相位方式、边界处理。离线零相位滤波使用未来数据，不能直接宣称同等实时延迟。

## 6. ICA 应如何理解

ICA 尝试把多通道混合分解为统计独立成分。它不会自动标注“这是眨眼”。正确流程是：在适当连续数据上拟合 → 检查成分时间序列、头皮分布、频谱和 EOG/ECG 相关 → 记录排除理由 → 重建并比较前后信号。

常见错误包括：数据太短、通道秩不匹配、在每个短 Epoch 单独拟合、一次删除过多成分、只看自动标签不人工复核。

## 7. 四种核心表示

| 表示 | 回答的问题 | 必须同时报告 |
|---|---|---|
| 原始波形 | 数据是否可信、伪迹何时发生？ | 单位、缩放、参考、滤波状态 |
| PSD | 功率分布在哪些频率？ | 方法、窗口、重叠、绝对/相对单位 |
| ERP | 事件锁定平均是否不同？ | Event、Epoch、基线、Trial 数、通道 |
| 时频图 | 功率何时在哪个频率变化？ | 基线、变换方法、色标单位、时间分辨率 |
| 头皮图 | 电极空间分布如何？ | 电极位置、插值、参考、时间/频段 |

## 8. 第一次数据审计练习

选择 EEGMMIDB 的一名受试者，完成：

1. 打印采样率、通道数、时长、单位和注释。
2. 画前 30 秒原始波形，标记至少一种可疑伪迹。
3. 画 1–45 Hz PSD，指出 Alpha、工频或高频肌电证据。
4. 比较原参考和平均参考下 O1/O2 的变化。
5. 写出“我能从这些图得出什么”和“还不能得出什么”。
