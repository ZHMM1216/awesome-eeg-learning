# EEG 基础

## 先理解测量，再处理信号

头皮 EEG 是大量突触后电位经脑组织、脑脊液、颅骨和头皮体积传导后的电势差。每个通道都是“活动电极减参考电极”，因此参考方式会改变所有通道的波形和拓扑。

## 最小预处理检查表

1. 核对单位、采样率、通道类型和电极名称。
2. 查看完整原始波形，而不是先滤波或切片。
3. 标记缺失/平直/饱和通道和记录中断。
4. 根据任务选择重参考、带通和陷波；记录全部参数。
5. 检查眼电、肌电、心电和运动伪迹；ICA 不是自动清洁按钮。
6. 确认事件时间、Epoch 边界和基线区间。
7. 在删除试次前后报告每名受试者保留数量。

## 常用表示

- 原始波形：发现漂移、饱和和短暂伪迹。
- Welch PSD：观察 Alpha、工频和频谱斜率。
- ERP：对事件锁定试次平均，提高相位锁定信号的信噪比。
- 时频图：观察非严格相位锁定的功率变化，如运动想象 ERD/ERS。
- 头皮图：展示电极空间分布，但不能直接等同于脑源位置。
