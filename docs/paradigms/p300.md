# Oddball / P300

Oddball 范式把高概率标准刺激与低概率目标刺激混合。目标被识别并与任务相关时，常在刺激后约 250–500 ms 出现顶中央较明显的正向 ERP，通常称为 P300/P3b。

## 学习目标

- 正确处理事件码、刺激锁定 Epoch、基线校正和条件平均。
- 理解 ERP 是跨试次平均后得到的条件相关电位，不是每个单试次都有清晰“尖峰”。
- 比较统计效应与单试次分类两个不同问题。

## 典型设计

| 元素 | 标准条件 | 目标条件 |
|---|---|---|
| 概率 | 约 70%–90% | 约 10%–30% |
| 任务 | 忽略或不反应 | 计数或按键 |
| 预期 | 较小 P3 | 顶中央 P3 增强 |
| 混杂 | 物理刺激差异、概率、反应要求可能同时变化 |

## 可复现分析配方

1. 画事件间隔和各事件数量，核对目标是否稀有。
2. 使用适合 ERP 的带通，例如 0.1–30 Hz；高通参数必须报告。
3. 取约 -0.2–0.8 秒 Epoch，在刺激前进行基线校正。
4. 先看单试次峰峰值和伪迹，再分别平均目标与标准条件。
5. 在 Cz/CPz/Pz 展示波形，在 P300 时间窗画头皮图。
6. 单试次解码从 xDAWN + 正则化 LDA 开始，并在 Trial/Block/Subject 层面正确划分。

## 数据与练习

- 入门数据：[OpenNeuro ds003061](https://openneuro.org/datasets/ds003061/versions/1.1.1)
- 练习 A：画目标减标准差异波，并预注册 P300 时间窗。
- 练习 B：比较普通平均、稳健平均和不同试次数量的影响。
- 练习 C：比较 ERP 统计差异与单试次 ROC-AUC，不把二者混为一谈。

## 常见错误

- 先看群体波形再挑峰值窗口，导致循环分析。
- 把标准和目标数量强行配平，却不说明丢弃了多少试次。
- 忽略按键反应，使运动电位与 P300 混在一起。
- 用窗口随机划分，让同一实验块的相邻试次同时进入训练和测试。
