# 睁眼 / 闭眼 Alpha

这是最适合第一次接触真实 EEG 的范式。人在安静闭眼时，枕区常出现更明显的约 8–13 Hz 节律；睁眼和视觉输入会使其减弱。它并不是诊断试验，而是检查采集、参考和频谱分析是否合理的教学入口。

![睁眼与闭眼条件下的概念性功率谱](../assets/figures/alpha-psd.svg)

*图解：先找 1/f 背景上的个体 Alpha 峰，再比较条件；不要只求 8–13 Hz 一个总数。*

### 这张图怎么读

闭眼曲线在约 10 Hz 有更明显峰，但低频背景仍然更高。真实分析应同时看 O1/O2/Oz 的谱、全头空间分布和每个人的峰频；仅凭群体平均峰不能保证每个人都有同样效应。

## 你要学会

- 从连续数据中找到睁眼和闭眼事件并切段。
- 同时看原始波形、功率谱密度和头皮空间分布。
- 区分绝对功率、相对功率和个体 Alpha 峰频率。
- 理解“群体常用 8–13 Hz”不等于每个人都有完全相同的边界。

## 范式设计

| 环节 | 建议设置 | 需要控制的因素 |
|---|---|---|
| 静息 | 坐姿或卧位，保持不动 | 姿势、环境光、困倦程度 |
| 睁眼 | 注视固定点 30–60 秒 | 眨眼和眼动会显著增加 |
| 闭眼 | 轻闭眼 30–60 秒 | 避免入睡和额肌紧张 |
| 重复 | 每种条件 3–5 段 | 条件顺序最好平衡 |

## 最小分析流程

1. 检查采样率、通道名、单位、参考和坏导。
2. 仅为教学分析使用约 1–40 Hz 滤波，并记录滤波器设计。
3. 按睁眼/闭眼事件切成长度一致的片段；剔除明显运动和饱和片段。
4. 用相同 Welch 参数估计两种条件 PSD。
5. 在 O1/O2/Oz 比较 8–13 Hz 绝对与相对功率，并画全头空间分布。
6. 对每位受试者分别报告，而不是只显示群体平均。

运行仓库示例：

```bash
python examples/alpha_eyes_open_closed.py --subject 1
```

示例使用 PhysioNet EEG Motor Movement/Imagery Database 的基线记录。第一次运行会下载少量公开数据。

## 结果检查清单

- Alpha 峰是否主要出现在枕区，而不是额极眼电通道？
- 两种条件是否使用完全相同的窗口长度与 PSD 参数？
- 50/60 Hz 工频峰、肌电高频活动是否被误当成神经节律？
- 个体没有明显 Alpha 峰时，是否如实报告而不是改变频段“追结果”？

    2. 为什么额区 10 Hz 增强不能立即叫作枕区 Alpha？

    **答案要点：**参数不同会改变谱估计；额区变化可能受参考、眼电或肌电影响；相对功率的分母也会变化，因此两种指标应明确区分。
