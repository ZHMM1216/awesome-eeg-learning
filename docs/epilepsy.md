# 癫痫 EEG

必须区分发作检测、发作预测、发作类型分类、癫痫诊断和异常波形检测。这些任务的标签、时间尺度和临床意义完全不同。

## 首个实验

使用 CHB-MIT 的少量连续记录：读取 EDF 和发作起止标注，将连续信号切为窗口，提取频带功率/谱熵等透明特征，建立简单分类基线。

## 正确评估

- 先按患者、记录和时间划分，再生成窗口。
- 报告事件敏感度、误报/小时和检测延迟。
- 明确发作前后容差、重叠规则和报警合并规则。
- 进阶评估遵循 [SzCORE](https://doi.org/10.1111/epi.18113)，大型临床语料使用 TUSZ。

!!! danger "不能直接用于报警"
    教学模型没有完成医疗器械验证，不能连接真实患者监护或发出临床报警。
