# 癫痫 EEG

癫痫是最容易被“切窗分类高分”误导的 EEG 方向之一。发作检测、发作预测、发作类型分类、异常波形检测和临床诊断的标签、时间尺度与用途完全不同。

![癫痫发作真值与模型报警时间线](assets/figures/seizure-event-metrics.svg)

*图解：两次发作都被检出仍可能存在不同延迟；无发作区间的一次报警计为误报。*

## 任务定义

| 任务 | 输入时间范围 | 输出 | 不能混淆为 |
|---|---|---|---|
| 发作检测 | 连续 EEG | 发作起止事件 | 癫痫诊断 |
| 发作预测 | 发作前与发作间期 | 未来风险/预警 | 事后检测 |
| 发作类型分类 | 已确认发作片段 | 临床发作类型 | 是否患癫痫 |
| 异常波形检测 | 短时 EEG | 棘波等候选事件 | 自动确诊 |
| 患者级诊断研究 | 完整检查与临床信息 | 诊断辅助结果 | 单片段分类 |

## 数据入口

| Dataset | 规模与特点 | 入门用途 | Access |
|---|---|---|---|
| [CHB-MIT](https://physionet.org/content/chbmit/1.0.0/) | 24 个病例、长时头皮 EEG、发作起止标注 | 首个连续检测流程 | 开放 |
| [TUSZ](https://isip.piconepress.com/projects/nedc/html/tuh_eeg/) | 大型临床发作语料、异构导联与记录 | 泛化和真实世界评估 | 注册并同意条款 |
| Bonn 片段数据 | 短片段、条件差异明显 | 非线性特征教学 | 不可当作连续临床检测证据 |

## CHB-MIT 入门实验

1. 读取少量 EDF 和官方发作起止标注，画出完整时间轴。
2. 统一或显式记录 Montage；不要只按通道顺序拼接不同记录。
3. 先按患者与时间划分训练/验证/测试，再生成窗口。
4. 提取频带功率、谱熵、线长等透明特征，建立 Logistic Regression 或树模型。
5. 把窗口概率通过平滑、阈值、最短持续时间和事件合并变成报警事件。
6. 按 SzCORE 定义报告事件敏感度、误报/小时和检测延迟。

仓库提供特征和事件指标示例：

```bash
python examples/clinical/seizure_features.py
```

## 为什么窗口 Accuracy 不够

连续记录中绝大多数时间无发作。把每个阴性窗口都算作样本会得到很高 Accuracy，但临床上可能每天产生大量误报。评价必须落到事件层面：一次发作是否被检测、何时检测、无发作时产生多少报警。

## 最低报告清单

- 患者数、发作数、总记录小时和排除规则。
- 训练、调参、测试的患者和时间划分。
- 发作前后容差、事件重叠和多报警合并规则。
- 事件敏感度、误报/小时、检测延迟及患者级分布。
- 阈值在哪里选择，是否使用了测试集。
- 对电极脱落、肌电、运动和记录系统变化的失败分析。

!!! danger "不能直接连接临床报警"
    本项目中的模型和阈值仅用于教学，没有完成医疗器械验证，不能连接真实患者监护或发出临床报警。

??? question "完成本节前自测"
    - 99% 窗口 Accuracy 是否一定好？若发作只占 1%，全预测无发作也可接近 99%。
    - 为什么同一发作的多个报警要合并？临床和事件指标通常关心一次发作事件，而非每个窗口。
    - 为什么测试患者不能参与阈值选择？否则事件敏感度和误报率会被乐观估计。
