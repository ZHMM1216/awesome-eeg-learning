# 连接性、微状态与源定位

多通道 EEG 让我们看到头皮上的空间结构，但头皮电位受到体积传导、参考和导电模型影响。连接性和源定位可以提出更丰富的问题，也更容易产生“漂亮但不可靠”的图。

## 三个层级

| 层级 | 输入 | 常见输出 | 能说什么 | 不能直接说什么 |
|---|---|---|---|---|
| 传感器空间 | 头皮通道 | 拓扑、协方差、相干 | 头皮分布和统计关系 | 某脑区就是唯一来源 |
| 源空间 | EEG + 头模/电极 | 皮层源时间序列 | 在模型假设下的来源估计 | 精确定位单个神经元群 |
| 网络空间 | 通道或源时间序列 | 连接矩阵、图指标 | 统计依赖或定向关系 | 解剖连接或因果机制 |

## 功能连接的五个问题

1. **幅值还是相位？** 相关、相干、PLV、AEC 衡量的不是同一件事。
2. **零相位成分怎样处理？** 体积传导会让多个通道瞬时相似；虚部相干、wPLI 等只能缓解部分问题。
3. **参考是否改变结果？** 共同参考会引入共享信号，必须做敏感性分析。
4. **边数怎样控制？** 64 通道已有 2016 条无向边；需要预定义网络或多重比较控制。
5. **方向性是否有足够证据？** Granger/传递熵依赖平稳性、模型阶数和采样，不能自动等于因果。

## EEG 微状态

![静息态频谱与微状态两类特征](../assets/figures/resting-state-features.svg)

微状态把短时间内相对稳定的头皮拓扑聚类为若干类别，再计算持续时间、出现率、覆盖率和转换。关键选择包括 GFP 峰、聚类数、跨被试模板、标签回配和时间平滑。类别字母 A/B/C/D 只是约定，必须用拓扑对齐后才能跨研究比较。

## 源定位最小工作流

1. 准确电极坐标与头皮配准。
2. 个体 MRI 或明确说明使用模板头模。
3. 建立 BEM/FEM 前向模型和噪声协方差。
4. 根据问题选择 MNE/dSPM/sLORETA/波束形成等逆解。
5. 用仿真或已知诱发反应检查空间偏差。
6. 在 ROI 层面做统计，并报告正则化和深度偏置设置。

!!! warning "定位精度不是图像分辨率"
    源图可以画得很细，但信息量受电极数、噪声、头模和逆问题不唯一性限制。平滑的彩色皮层图不等于毫米级定位证据。

## 入门任务

- 在同一段睁眼/闭眼数据上比较平均参考和乳突参考的相干矩阵。
- 使用模拟的单个偶极源，观察不同电极数和噪声对定位结果的影响。
- 对微状态分别使用 4、5、6 类，比较解释方差与重测稳定性，而不是只挑最显著分类结果。
